# Grad Center Agentic AI Assistant

## Context
Generic system, but uses CSULB Graduate Center pages as data source.

## Capabilities
- Step-by-step guidance
- Checklist generation
- Progress tracking
- Context-aware responses
- Precise answers

## Rules
- Always return structured output (JSON or list)
- Avoid generic paragraphs
- Use retrieved content from university pages
- Include source when possible
- Suggest next steps
- If unsure, say "I don't know"

## Constraints
- No direct integrations
- Use simple retrieval (text/JSON)
- Keep logic modular
